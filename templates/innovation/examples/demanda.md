# Demanda bruta (exemplo)

Toda semana perco tempo consolidando manualmente os boletos de várias
prefeituras para os clientes do escritório. Queria um serviço que baixasse,
conciliasse e avisasse o cliente sozinho. Aliás, nosso processo de onboarding
de cliente novo também é uma bagunça — cada contador faz de um jeito.

Acho que dá para cobrar uns R$ 99/mês disso. Será que já existe algo assim?
